이미지 처리 도구

Python 기반의 간편한 이미지 처리 CLI 도구 모음. 흑백 변환과 대머리 효과를 한 줄 명령어로 적용하세요.

Python 3 OpenCV Pillow CLI

흑백 변환

컬러 이미지를 그레이스케일(흑백)로 변환합니다. Pillow 라이브러리를 사용하여 빠르고 정확하게 처리합니다.

# 흑백 변환 실행
$ python convert_to_black.py photo.jpg
# 결과: photo_black.jpg 생성

대머리 효과

얼굴을 자동 감지하고 머리카락 영역을 제거하여 자연스러운 대머리 효과를 적용합니다.

# 대머리 효과 실행
$ python make_bald.py photo.jpg
# 결과: photo_bald.jpg 생성

설치 방법

1

저장소 클론

$ git clone https://github.com/dodo9944-ops/813700.git

실행
